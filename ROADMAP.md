# Roadmap

## F0: Project Defined

- Establish charter, Run Contract, scope, glossary, deliverables register, authority, risks, and project constitution.

## F1: Architecture Coherent

- Lock identity, revision, anchor, provenance, lifecycle, canonicality, and mutation contracts.
- Reconcile candidate component specifications against the shared kernel.
- Eliminate critical cross-spec contradictions.

## F2: Substrate Executable

- Materialize the reference vault.
- Implement schema validation, atomic Sheet writes, manifest rendering, cache rebuild, and minimal compile.

## F3: Trust Proven

- Force crash and recover.
- Corrupt SQLite and rebuild.
- Create competing file edits and preserve both.
- Apply and reverse a governed patch.
- Export and restore a project archive.

## F4: Writer Value Demonstrated

- Run professional-workflow and six-hour fatigue assays.
- Validate editor dominance, return-to-sentence behavior, keyboard operation, and performance budgets.

## Sequencing rule

The Compendium, semantic recall, graph projections, and broad AI functionality remain schema-aware but implementation-deferred until the editor, manuscript machine, and recovery substrate pass their gates.
