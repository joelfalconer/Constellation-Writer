The v0.2 documents are revised candidate specifications derived from the earlier component drafts and reconciled against the Product Constitution, Canonicality Matrix, identity model, Mutation Envelope, and F1 executable decision evidence.

They are not all accepted contracts. Promotion requires schema validation, cross-spec consistency checks, reference-fixture exercise, and the relevant foundation gate.

## Compile authority correction

Compile Contract v0.2 supersedes v0.1 for F1 review. It makes the Manuscript Manifest the sole assembly authority for order, membership and semantic placement role; limits Compile Profiles to explicit export scope and target-format treatment; and keeps the frozen compile plan, Workbench AST, QA and source maps under Constellation ownership. External document converters remain output adapters rather than canonical compilers.
