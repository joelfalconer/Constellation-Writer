# Journey: Screenplay Development

## Goal

Write and rearrange scenes with script-aware behavior while retaining the same durable project and recovery model as prose work.

## Journey

1. Create a script manuscript and Fountain-compatible Sheet.
2. Write scene headings, dialogue, action, and transitions with keyboard-first behaviors.
3. Navigate scenes by manuscript placements.
4. Reorder a scene without changing its text file identity.
5. Run script-specific validation and compile.
6. Export through a specialist-compatible adapter.

## Boundary

Script-specific semantics may extend the editor and compile pipeline, but must not make ordinary manuscript Sheets depend on screenplay rules.

## Acceptance measures

- Fountain round-trip fixture;
- scene order independent of file path;
- deterministic script compile semantics;
- no screenplay extension required for prose projects.
