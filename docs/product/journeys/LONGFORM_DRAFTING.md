# Journey: Longform Drafting Day

## Goal

Resume a large manuscript quickly, write for hours, move between scenes when necessary, and finish without thinking about storage machinery.

## Entry state

The writer may be fatigued, interrupted, or returning after days away.

## Journey

1. Open project and return to the last meaningful sentence.
2. Begin typing without a dashboard or setup step.
3. Autosave locally without visible interruption.
4. Summon navigator only when changing scene or chapter.
5. Create a new Sheet from the keyboard when a structural break is useful.
6. Use quick open for a half-remembered scene, then return to the original position.
7. End session with clear saved/snapshot state.

## Failure risks

- editor demotion by navigation chrome;
- scroll/cursor displacement after pane toggles;
- autosave anxiety or noisy save UI;
- slow search causing context loss;
- background indexing affecting typing.

## Acceptance measures

- time to first editable sentence;
- p95 input latency;
- return-token fidelity;
- zero silent loss;
- no canonical file churn from cursor/scroll state.
