# Journey: Transmedia Continuity Check

## Goal

Inspect continuity around active writing without moving into a separate wiki-shaped application.

## Journey

1. Draft normally with Compendium hidden.
2. Select an entity name or open the current-Sheet inspector.
3. View accepted claims and their manuscript evidence.
4. Inspect a contradiction if present.
5. Jump to both evidence locations.
6. Decide whether to revise prose, alter claim scope, preserve intentional ambiguity, or defer.
7. Return to the prior writing position.

## Boundary

The Compendium is subordinate. AI extraction creates candidates only. Graph projection is optional analysis, never required navigation.

## Acceptance measures

- claim/evidence jump and return are reliable;
- candidate AI claims never enter active canon automatically;
- alternate continuity scope prevents false contradiction warnings.
