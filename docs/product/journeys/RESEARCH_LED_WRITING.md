# Journey: Research-Led Writing

## Goal

Move between source material and prose with traceability while avoiding PKM maintenance as a second job.

## Journey

1. Open or capture a research/source Sheet.
2. Search for literal text, source metadata, or a half-remembered passage.
3. Jump to evidence and return to the writing sentence.
4. Insert a citation or source link without polluting prose with machine metadata.
5. Draft synthesis in a manuscript Sheet.
6. Optionally create or review a Compendium claim tied to evidence.
7. Compile with citation and unresolved-source QA.

## Failure risks

- source browser replacing the editor;
- derived search results becoming canonical facts;
- inferred claims being presented as observed evidence;
- broken source links after file moves.

## Acceptance measures

- every saved claim can expose evidence or explicitly state none;
- search result always has a return path;
- external sources and copied extracts preserve provenance.
