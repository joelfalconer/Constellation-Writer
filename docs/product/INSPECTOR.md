# Inspector Contract v0.1

## Purpose

The Inspector exposes information and instruments about the current object or selection. It remains subordinate to the editor.

## Contexts

### Sheet

- title, kind, status, labels, summary;
- compile default and resolved inclusion;
- word target;
- privacy and AI-context policy;
- revision and file locator.

### Selection

- annotations;
- citations and sources;
- entity mentions and claim evidence;
- patch provenance;
- transformation commands.

### Manuscript placement

- role, inclusion, title behavior, break behavior;
- parent and children;
- shared Sheet usage.

### Conflict or warning

- exact issue;
- affected object and scope;
- evidence or validation rule;
- safe repair actions.

## Laws

- The Inspector never becomes mandatory for basic drafting.
- Context changes do not steal editor focus unless requested.
- Canonical edits use registered commands and Mutation Envelopes.
- Derived findings are labelled and can be dismissed or promoted through review.
- Closing the Inspector restores editor width without scroll displacement.
