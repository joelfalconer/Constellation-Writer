# Surface Jurisdictions

| Surface | Owns | Must not become |
|---|---|---|
| Editor | prose, selection, cursor, active revision overlays | dashboard, graph canvas, permanent chat pane |
| Navigator | location, manuscript tree, recent context, filters | canonical filesystem editor, metadata wall |
| Inspector | current-object metadata, annotations, evidence, warnings | second workspace, global dashboard |
| Command palette | commands, quick open, scoped search, transformations | persistent assistant surface |
| Search/recall | retrieval, result explanation, jump and return | canonical organizer |
| Compile | resolved assembly, transforms, QA, preview, artifacts | prose editor |
| Compendium | entities, claims, evidence, conflict review | primary writing surface or general PKM |
| Recovery | save state, snapshots, conflicts, restore | noisy monitoring console |

## Laws

1. The editor receives the largest and most stable visual territory.
2. Summoned surfaces preserve and restore editor selection, cursor, scroll, and mode.
3. A warning appears nearest to the decision that can resolve it, without permanently colonizing the prose field.
4. Global analysis lives outside the editor unless the writer activates a revision overlay.
5. No surface may create canonical state without using its declared mutation route.
