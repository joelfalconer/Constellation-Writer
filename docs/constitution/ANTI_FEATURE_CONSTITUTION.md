# Anti-Feature Constitution

Constellation Writer deliberately refuses the following defaults.

## Product anti-features

- A dashboard surrounding a small editor.
- Block-based manuscript storage.
- Cloud-only projects.
- Mandatory account login for local writing.
- Filesystem order presented as manuscript order.
- Titles or paths used as durable identity.
- Always-on AI chat or ghost completion.
- Silent AI, script, import, or repair mutations.
- Graph-first navigation.
- Compendium maintenance as a prerequisite to drafting.
- Export that hides inclusion, transformation, or loss.
- Plugin dependency for core writing, compile, or recovery.
- Real-time collaboration before solo reliability.
- Opaque project packages that cannot be inspected as files.

## Governance

An anti-feature may be reconsidered only through an ADR that:

1. names the user problem;
2. proves the existing boundary blocks material value;
3. shows how sovereignty and recovery invariants remain intact;
4. defines rollback and deprecation conditions;
5. passes professional workflow testing.
