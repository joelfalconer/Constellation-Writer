# Workflow and Friction Map v0.1

| Workflow | Desired state | Common friction class | Design response | Evidence needed |
|---|---|---|---|---|
| start/resume | return immediately to meaningful context | launch detour, lost location | recent-context return token with fallback | measured resume tests |
| draft | stable prose flow | chrome, lag, analysis noise | Editor Doctrine, Draft mode, latency budget | six-hour assay |
| structure | move chunks without text surgery | folder/order conflation | placement IDs and manifest order | binder prototype |
| recall | find known and half-known material | weak search, graph detour | layered search with explained results | precision/recall tasks |
| revise | inspect changes without visual overload | overlapping diagnostics | individually governed overlays | revision usability tests |
| annotate | comments survive edits and remain private | inline clutter, stale anchors | dedicated annotation logs and hybrid anchors | split/merge/re-anchor tests |
| research | sources remain adjacent and attributable | disconnected notes or PKM gardening | source records and material Sheets | research-led writer studies |
| compile | output matches intent | hidden inclusion and lossy transforms | frozen plan, QA, source map | golden outputs |
| AI assist | useful transformation without authorship loss | silent rewrite, context leakage | ContextPack and PatchSession | patch review and privacy tests |
| recover | understand what is safe under stress | vague errors, overwrite, restore fear | buffers, snapshots, conflict bundles, calm copy | failure injection |
| handoff | share clean manuscript without private debris | archive leakage, format mismatch | handoff archive preset | privacy and editor tests |

## Cross-workflow tensions

- Rich metadata versus clean external files.
- Immediate autosave versus durable transaction history.
- Deep recall versus derived-index dependence.
- Rich annotations versus stable span anchoring.
- Compile flexibility versus deterministic simplicity.
- Provenance retention versus privacy and archive size.
