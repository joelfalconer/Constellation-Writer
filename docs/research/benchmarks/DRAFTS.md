## Product thesis

The current corpus identifies Drafts as the text-first capture, routing, and automation benchmark.

## Atomic affordances to benchmark

- near-zero-friction capture;
- immediate text focus on launch;
- routing text to a destination without modal ceremony;
- command/action discoverability;
- automation that remains explicitly user-triggered.

## Borrow / reject / test

**Borrow:** text-first entry, command routing, explicit actions.

**Reject:** turning the writing workbench into an automation launcher or requiring action configuration for ordinary writing.

**Test:** whether command palette and import/routing flows can preserve capture speed while maintaining canonical project contracts.

## Unknowns

The current evidence set does not atomize individual actions, mobile workflows, or failure/recovery characteristics.
