# Benchmark Dossiers

Each dossier must record:

- product and exact version/date;
- official-source feature evidence;
- observed workflow behavior;
- smallest useful affordances;
- cognitive and ergonomic effects;
- export, ownership, recovery, and interoperability behavior;
- complaints and switching evidence with source quality;
- what Constellation should borrow, reject, or test;
- uncertainty and stale-information warnings.

Required initial dossiers:

- Ulysses
- Scrivener
- iA Writer
- Drafts
- Obsidian
- Final Draft
- Vellum
- Atticus
- plain-text developer-author workflow

Do not publish feature grids without atomic workflow descriptions and versioned evidence.
