# Complaint and Switching Map v0.1

This is a candidate synthesis from the prior workbench report and design conversation. It requires later review against exact source locators and current user research.

| Starting condition | Trigger | Destination behavior sought | Constellation implication |
|---|---|---|---|
| calm editor | project grows structurally complex | binder, alternate order, compile | keep editor calm while adding manifest control |
| powerful manuscript suite | daily drafting feels heavy | faster launch, cleaner prose surface | separate Writer Chair from full project machinery |
| plain Markdown vault | export and assembly become brittle | deterministic profiles and QA | own manuscript manifest and compile plan |
| graph/PKM tool | manuscript becomes one object among many | prose-first hierarchy | graph remains derived and optional |
| AI writing tool | author distrusts invisible changes | reviewable diff and provenance | PatchSession membrane |
| cloud editor | ownership or offline concerns | local files and archives | no account/network dependency |
| specialist format tool | research and longform context fragment | integrated materials and sources | support adapters without surrendering canonical format |

## Switching risks for Constellation Writer

- Too much schema before first useful sentence.
- File sovereignty exposed as folder administration.
- Compile power arriving with Scrivener-like cognitive weight.
- AI governance becoming bureaucratic instead of reassuring.
- Compendium scope turning the product into a second app.
- Cross-platform WebView differences undermining editor trust.

## Required research

Interview switchers, capture the exact incident that caused the switch, distinguish chronic irritation from critical failure, and measure which paired-tool workflows users refuse to abandon.
