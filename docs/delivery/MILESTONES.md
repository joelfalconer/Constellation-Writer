# Milestones and Gates

## M0 Foundation Defined

Outputs: charter, constitution, scope, users, deliverables, contracts, reference fixture.  
Gate: F0 human acceptance.

## M1 Architecture Coherent

Outputs: machine-checked schemas, reconciled authorities and enums, technology spikes, F1 receipt.  
Gate: no critical contract drift.

## M2 Durable Writing Vertical Slice

Outputs: create/open project, edit Sheet, atomic save, crash recovery, manifest binder, cache rebuild.  
Gate: zero silent loss in implemented fault tests.

## M3 Manuscript Compile Slice

Outputs: resolved compile plan, Markdown/HTML and DOCX candidate output, QA, source map, golden tests.  
Gate: deterministic semantic output.

## M4 Governed Transformation Slice

Outputs: proposed patch, review, partial acceptance, apply, stale detection, reversal.  
Gate: no non-human direct mutation.

## M5 Professional Writer Alpha

Outputs: integrated desktop prototype and assay results.  
Gate: core workflow value demonstrated with real writers.

## M6 Continuity Boundary

Outputs: entity, claim, evidence, and conflict Inspector on top of proven manuscript substrate.  
Gate: Compendium helps current writing without becoming primary workspace.
