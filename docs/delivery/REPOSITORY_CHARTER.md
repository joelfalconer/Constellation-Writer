# Repository Charter

`joelfalconer/Constellation-Writer` is the canonical repository for the Constellation Writer product definition, contracts, fixtures, implementation, validation, and release history.

## Authority

- `main` contains accepted or explicitly provisional integrated state.
- Feature/foundation branches contain candidate work.
- A document is not canonical merely because it is merged; its status field and gate receipt determine validation state.
- Sandboxes and generated reports are noncanonical until committed with provenance and review.

## Required repository qualities

- contracts are machine-readable where practical;
- examples are executable fixtures;
- architecture decisions use ADRs;
- high-consequence changes include tests and rollback notes;
- generated artifacts are labelled and reproducible;
- no secrets or private manuscript corpora enter the public repository.
