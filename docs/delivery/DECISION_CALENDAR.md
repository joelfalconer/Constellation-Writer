# Decision Calendar

| Decision | Latest safe point | Evidence required |
|---|---|---|
| typed UUIDv7 format | before persistent prototype data | schema validation and migration review |
| Sheet frontmatter minimum | before editor persistence | external editor test |
| annotation event format | before comments implementation | re-anchor and split/merge tests |
| Tauri or Electron shell | before application scaffold | cross-platform shell spike |
| CodeMirror or rival editor engine | before editor feature build | prose, IME, accessibility, long-Sheet spike |
| SQLite catalog schema | before recall/index implementation | rebuild and scale assay |
| compile AST and adapter boundary | before DOCX/EPUB implementation | golden-output spike |
| array order or order keys | before app-managed sync | solo binder test; revisit on concurrency |
| patch retention policy | before remote AI beta | privacy and rollback tests |
| publication-state format | before first external release | source-map and archive test |

Decisions move earlier only when their evidence is available. They do not become accepted because implementation has accidentally depended on them.
