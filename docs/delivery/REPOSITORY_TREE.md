# Repository Tree

```text
apps/                 runnable product applications
packages/             bounded runtime packages
contracts/            machine-readable domain contracts
registries/           shared enums, states, decisions, risks, commands
fixtures/             valid and invalid reference projects
research/ or docs/research/ evidence and source records
docs/programme/       project identity, scope, outcomes, receipts
docs/constitution/    highest-authority laws and matrices
docs/architecture/    system and transaction architecture
docs/specifications/  component contracts
docs/product/         workflows and interaction systems
docs/validation/      assays, budgets, drills, gate reports
docs/delivery/        backlog, setup, release and operating plans
tools/                validators, migrations, fixture builders, benchmarks
tests/                executable contract, integration, recovery and compile tests
.github/               CI and contribution automation
```

Directories are created when their first durable artifact exists. Empty placeholder directories are avoided where Git cannot preserve them.
