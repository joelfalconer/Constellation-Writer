# Workstream Map

## Writer Experience

Editor shell, typography, modes, navigation, commands, accessibility, ergonomics, recall behavior.

## Durable Substrate

Vault scanning, contracts, atomic I/O, IDs, revisions, manifests, SQLite catalog, migration.

## Manuscript Machine

Binder, alternate assembly, compile plan, Workbench AST, adapters, QA, source maps, publication state.

## Trust and Transformation

Mutation Envelope, PatchSession, snapshots, archives, conflicts, restore, provenance, privacy.

## Continuity Sidecar

Entities, claims, evidence, scope, conflict inspection. Broad graph and automated extraction remain deferred.

## Validation

Fixtures, validator, negative controls, performance, accessibility, privacy, failure injection, gate receipts.

## Coordination rule

Every workstream change names:

- affected invariants;
- canonical fields written;
- cross-package dependencies;
- tests and recovery path;
- gate and milestone impact.
