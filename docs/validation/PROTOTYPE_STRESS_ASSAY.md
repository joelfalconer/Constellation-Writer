# Prototype Stress Assay v0.1

## Purpose

Determine whether Constellation Writer is genuinely better for sustained professional writing, rather than merely feature-complete.

## Benchmark set

- Constellation Writer prototype.
- Ulysses or closest available calm library/editor benchmark.
- Scrivener or closest available manuscript-control benchmark.
- iA Writer or closest available editor-instrument benchmark.
- Plain Markdown editor plus filesystem baseline.

Benchmark availability and versions must be recorded for each run.

## Reference project

Use a project with:

- 100,000 manuscript words across at least 80 Sheets;
- nested Parts, Chapters, and Scenes;
- excluded material and alternate arrangement;
- 200 research notes;
- annotations and unresolved comments;
- at least one compile profile;
- simulated stale index and external conflict.

## Core tasks

1. Launch and resume the last sentence.
2. Draft 1,000 words without touching a pointer.
3. Create, rename, split, move, and merge Sheets.
4. Find a half-remembered phrase.
5. Find every occurrence of an entity name.
6. Exclude a scene and explain its export state.
7. Compile a clean draft.
8. Recover after forced termination.
9. Reconcile an external edit conflict.
10. Review and partially accept a three-hunk patch.
11. Revert the accepted patch.
12. Delete derived state and rebuild.

## Measures

- task completion time;
- keystrokes and pointer actions;
- interruption-recovery time;
- cursor or scroll preservation failures;
- mode errors;
- search precision and recall;
- export confidence rating;
- save anxiety rating;
- observed hesitation and recovery behavior;
- p50 and p95 interaction latency.

## Hard gates

- zero silent data loss;
- no typing blocked by indexing or save;
- no unexplained export inclusion;
- no non-human mutation without review;
- successful cache rebuild;
- successful archive restore;
- core tasks keyboard-operable.

## Six-hour protocol

Run repeated 30-minute cycles of drafting, structural change, search, compile, and return. Record accumulated visual residue, performance degradation, errors, and subjective fatigue at hours 1, 3, and 6.

## Reporting

Each run emits:

- environment and versions;
- task-level measurements;
- failures and critical incidents;
- comparison notes;
- hard-gate results;
- recommended changes;
- validation state and reviewer.
