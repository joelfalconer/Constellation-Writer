## Adversarial results

### Mutation ownership

Selected: **Mutation Envelope as sole canonical application authority**.

Rejected serious rivals:

- PatchSession as universal transaction engine;
- Recovery as universal transaction engine;
- separate canonical transaction semantics for autosave, AI, migration, and restore.

Jurisdictions now separate proposal/review, application, preservation/restore mechanisms, and durable outcome history.

### Compile authority

The stale authority statement `manuscript_manifest_with_compile_profile_override` was removed. Manuscript Manifest is sole assembly-membership authority. Compile Profiles may project and render but may not redefine order, membership, or semantic role.

### User state

Cursor, scroll, pane layout, and recent context remain local/noncanonical. Future portable handoff state may exist only as optional and non-authoritative unless explicitly re-governed.

### Identity

Typed UUIDv7 is accepted before durable prototype data. Path/title identity is rejected by hard invariant; ULID and UUIDv4 remain documented serious alternatives without sufficient benefit to displace UUIDv7.

### Annotations

Dedicated annotation logs remain a candidate direction, **not canonical authority**. PR review caught and repaired a closure-delta inconsistency where the Canonicality Matrix had prematurely named `annotation_log` as canonical while ADR-0008 was deferred. The matrix now carries annotations under `deferred_authority` until F2 storage/reanchor/sync/compaction assays pass.
