# Anti-Personas and Deliberate Non-Fit

Constellation Writer is not initially optimized for:

## The General Task Manager

A user seeking project dashboards, meetings, kanban boards, databases, and team coordination as the primary experience.

## The Graph Gardener

A user whose central activity is creating backlinks, maps, and knowledge-network visualizations independent of a manuscript.

## The One-Click AI Content Operator

A user seeking bulk autonomous content generation, silent rewriting, or high-volume publication with minimal authorship review.

## The Real-Time Collaborative Team

A team needing Google Docs-style concurrent editing, permissions, comments, and presence in the first release.

## The Page-Layout Specialist

A user seeking InDesign-class typography and final page composition as the primary environment.

## The Casual Notes User

A user who only needs lightweight capture and short notes may find the product unnecessarily structured.

These exclusions are sequencing choices, not eternal prohibitions. Any expansion must preserve editor sovereignty and the canonical substrate.
