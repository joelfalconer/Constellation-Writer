# Success Definition

## Product success

Constellation Writer succeeds when a serious writer voluntarily returns to it for daily work because it reduces friction and anxiety without reducing control.

## Foundation success

- Every durable field has one canonical owner.
- All derived state can be deleted and rebuilt.
- Manuscript order and compile semantics are deterministic.
- No non-human process silently mutates canonical state.
- Crash, corruption, conflict, bad patch, and archive restore tests have explicit outcomes.

## Writer-experience success

- Time to first word and time to resume are consistently low.
- Core workflows are keyboard-operable.
- Summoned tools return the writer to the prior sentence and context.
- Editor responsiveness does not degrade during background indexing.
- Long-session testing reveals no accumulating interface residue.

## Trust success

- Zero silent data-loss events in the failure-injection suite.
- Writers can explain what is saved, what is backed up, and what changed.
- Export preview and QA explain inclusion and transformation.
- AI-assisted changes remain attributable and reversible.

## Initial outcome signals

- Writers choose the prototype over their existing tool for at least one real workflow.
- A reference project survives cache deletion, crash recovery, external conflict, compile, archive, and restore.
- Foundation gates close with receipts rather than aspirational claims.
