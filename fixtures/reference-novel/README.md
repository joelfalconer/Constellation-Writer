# Reference Novel Fixture

This fixture is the small executable universe used to validate the architecture.

It currently contains a minimal project manifest, manuscript, two Sheets, and sidecars. Planned additions include excluded material, alternate assembly, annotations, compile profiles, claims, stale evidence, patches, conflicts, corrupted cache, snapshots, and an archive.

The fixture must remain human-readable and must open after all `.workbench/` state is deleted.
