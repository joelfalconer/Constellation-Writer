# Constellation Writer

Constellation Writer is a local-first professional writing workbench for serious longform work.

The project is being established through a contract-first, fixture-first, vertical-slice-first programme. The editor remains the sovereign writing surface; plain-text files and manifests hold durable project truth; derived indexes provide speed; transformations remain reviewable and reversible.

Project foundation work is being developed on a review branch before promotion to `main`.
